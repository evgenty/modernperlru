Глава 6: Регулярные выражения

Регулярные выражения и сопоставление

Перл называют Practical Extraction and Reporting Language. Регулярные выражения позволяют Перлу быть особенно эффективным для обработки текста.

Литералы

Простейшее регулярное выражение — это поиск подстроки:

my $name = 'Chatfield';
say 'Нашли шляпу!' if $name =~ /hat/;

Оператор сопоставления =~ связывает строку слева и шаблон справа. Оператор !~ — это отрицание сопоставления.

Замена

Оператор замены s/// меняет найденную подстроку:

my $status = 'I feel ill.';
$status =~ s/ill/well/;
say $status;

Оператор qr//

Создание регулярных выражений как объектов:

my $hat = qr/hat/;
say 'Нашли шляпу!' if $name =~ /$hat/;

И комбинирование:

my $field = qr/field/;
say 'Нашли шляпу на поле!' if $name =~ /$hat$field/;

Квантификаторы

Квантификаторы управляют количеством повторений элемента.

Ноль или один: ?

my $cat_or_ct = qr/ca?t/;
like 'cat', $cat_or_ct, "'cat' соответствует /ca?t/";
like 'ct', $cat_or_ct, "'ct' соответствует /ca?t/";

Один или более: +

my $some_a = qr/ca+t/;
like 'cat', $some_a, "'cat' соответствует /ca+t/";
like 'caat', $some_a, "'caat' соответствует /ca+t/";
like 'caaat', $some_a, "'caaat' соответствует /ca+t/";
like 'caaaat', $some_a, "'caaaat' соответствует /ca+t/";
unlike 'ct', $some_a, "'ct' не соответствует /ca+t/";

Ноль или более: *

my $any_a = qr/ca*t/;
like 'cat', $any_a, "'cat' соответствует /ca*t/";
like 'caat', $any_a, "'caat' соответствует /ca*t/";
like 'caaat', $any_a, "'caaat' соответствует /ca*t/";
like 'caaaat', $any_a, "'caaaat' соответствует /ca*t/";
like 'ct', $any_a, "'ct' соответствует /ca*t/";

Точное количество повторений: {n}

my $only_one_a = qr/ca{1}t/;
like 'cat', $only_one_a, "'cat' соответствует /ca{1}t/";

От n повторений: {n,}

my $some_a = qr/ca{1,}t/;
like 'cat', $some_a, "'cat' соответствует /ca{1,}t/";
like 'caat', $some_a, "'caat' соответствует /ca{1,}t/";
like 'caaat', $some_a, "'caaat' соответствует /ca{1,}t/";
like 'caaaat', $some_a, "'caaaat' соответствует /ca{1,}t/";

От n до m повторений: {n,m}

my $few_a = qr/ca{1,3}t/;
like 'cat', $few_a, "'cat' соответствует /ca{1,3}t/";
like 'caat', $few_a, "'caat' соответствует /ca{1,3}t/";
like 'caaat', $few_a, "'caaat' соответствует /ca{1,3}t/";
unlike 'caaaat', $few_a, "'caaaat' не соответствует /ca{1,3}t/";

Краткие квантификаторы (? + *) чаще используются на практике, так как они читаются проще.

Жадность

Квантификаторы + и * жадные: они пытаются сопоставить как можно больше текста.

my $hot_meal = qr/hot.*meal/;
say 'Нашли горячую еду!' if 'I have a hot meal' =~ $hot_meal;
say 'Нашли горячую еду!' if 'one-shot, piecemeal work!' =~ $hot_meal;

Модификатор ? превращает жадный квантификатор в нежадный:

my $minimal_greedy = qr/hot.*?meal/;
say 'Нашли горячую еду' if 'ilikeahotmeal' =~ /$minimal_greedy/;

Аналогично для +?:

my $minimal_greedy_plus = qr/hot.+?meal/;
unlike 'ilikeahotmeal', $minimal_greedy_plus;
like 'i like a hot meal', $minimal_greedy_plus;

Якоря в регулярных выражениях

Якоря фиксируют позицию начала или конца совпадения.

my $seven_down = qr/\Al${letters_only}{2}m/;
my $seven_down = qr/\Al${letters_only}{2}m\z/;

\A соответствует только началу строки, \z — только концу строки.

\b соответствует границе слова:

my $seven_down = qr/\bl${letters_only}{2}m\b/;

Перл 5.22 добавил более точный якорь \b{wb} для поддержки Юникода:

say "Паника" if "Don't Panic" =~ /Don\b/;
say "Нет паники" unless "Don't Panic" =~ /Don\b{wb}/;

Метасимволы

Метасимволы дают регулярным выражениям дополнительную силу:

  • . — любой символ кроме перевода строки
  • \w — символ слова (буквы, цифры, подчёркивание)
  • \d — цифра
  • \s — пробельный символ
next unless $word =~ /l\w\wm/;
next unless $number =~ /\d{3}-\d{3}-\d{4}/;

Отрицательные метасимволы

  • \W — не-слово
  • \D — не-цифра
  • \S — не-пробел
  • \B — не-граница слова

Классы символов

Классы символов группируют символы в одну группу:

my $ascii_vowels = qr/[aeiou]/;
my $maybe_cat = qr/c${ascii_vowels}t/;

Чтобы избежать ошибок интерполяции переменных, используйте скобки {}.

Диапазоны символов можно задавать через дефис:

my $ascii_letters_only = qr/[a-zA-Z]/;

Чтобы включить дефис в класс символов, поставьте его первым, последним или экранируйте:

my $interesting_punctuation = qr/[-!?]/;
my $line_characters = qr/[|=\-_]/;

Отрицание класса символов через ^:

my $not_an_ascii_vowel = qr/[^aeiou]/;

Захват

Регулярные выражения позволяют группировать и захватывать части совпадений для дальнейшего использования.

my $area_code = qr/\(\d{3}\)/;
my $local_number = qr/\d{3}-?\d{4}/;
my $phone_number = qr/$area_code\s?$local_number/;

Чтобы экранировать скобки, нужно использовать обратный слэш.

Именованные захваты

Именованный захват позволяет получить часть совпадения по имени:

if ($contact_info =~ /(?<phone>$phone_number)/) {
say "Найден номер $+{phone}";
}

Именованная форма записи: (?<имя>...). После успешного сопоставления данные попадают в хеш %+.

Нумерованные захваты

Можно использовать и стандартные нумерованные захваты:

if ($contact_info =~ /($phone_number)/) {
say "Найден номер $1";
}

Первое совпадение — в $1, второе — в $2 и так далее. В списочном контексте:

if (my ($number) = $contact_info =~ /($phone_number)/) {
say "Найден номер $number";
}

В подстановках также можно использовать захваченные значения:

my $order = 'Vegan brownies!';
$order =~ s/Vegan (\w+)/Vegetarian $1/;
$order =~ s/Vegan (?<food>\w+)/Vegetarian $+{food}/;

Группировка и Альтернативы

Квантификаторы можно применять к любым элементам регулярного выражения:

my $pork = qr/pork/;
my $beans = qr/beans/;
like 'pork and beans', qr/\A$pork?.*?$beans/, 'может быть pork, обязательно beans';

Для большей точности:

my $pork = qr/pork/;
my $and = qr/and/;
my $beans = qr/beans/;
like 'pork and beans', qr/\A$pork? $and? $beans/, 'может быть pork, может быть and, обязательно beans';

Альтернация

Альтернативы позволяют выбрать одно из нескольких возможных совпадений:

my $rice = qr/rice/;
my $beans = qr/beans/;
like 'rice', qr/$rice|$beans/, 'Найден рис';
like 'beans', qr/$rice|$beans/, 'Найдены бобы';

Альтернация имеет низкий приоритет. Лучше группировать варианты явно:

my $starches = qr/(?:pasta|potatoes|rice)/;

Примечание: Строковое представление регулярки включает некаптурирующую группу: qr/rice|beans/ превращается в (?^u:rice|beans).

Другие экранирующие последовательности

Чтобы сопоставить литеральный экземпляр метасимвола, экранируйте его с помощью обратного слэша (\).

my ($text, $literal_text) = @_;
return $text =~ /\Q$literal_text\E/;

Конструкция \Q...\E отключает интерпретацию метасимволов внутри себя — полезно при работе с пользовательским вводом.

Безопасность регулярных выражений

Будьте осторожны при обработке пользовательских регулярных выражений: возможны атаки отказа в обслуживании через специально сконструированные паттерны.

Ассерты (Assertions)

Ассерты не потребляют символы строки, а проверяют условия в определённых точках.

my $just_a_cat = qr/cat\b/;
my $safe_feline = qr/cat(?!astrophe)/;
my $disastrous_feline = qr/cat(?=astrophe)/;

Примеры:

  • (?!...) — отрицательная проверка вперёд
  • (?=...) — положительная проверка вперёд
  • (?<!...\) — отрицательная проверка назад
  • (?<=...) — положительная проверка назад
my $middle_cat = qr/(?<!\A)cat/;
my $space_cat = qr/(?<=\s)cat/;

Ассерт \K

Ассерт \K позволяет отбросить часть совпадения до него:

my $spacey_cat = qr/\s+\Kcat/;
like 'my cat has been to space', $spacey_cat;
like 'my cat has been to doublespace', $spacey_cat;

Это особенно полезно для аккуратных замен:

my $exclamation = 'This is a catastrophe!';
$exclamation =~ s/cat\K\w+!/./;
like $exclamation, qr/\bcat\./, "That wasn't so bad!";

До \K текст участвует в совпадении, но в замену попадает только то, что после.

Модификаторы регулярных выражений

Модификаторы изменяют поведение операторов поиска, замены и qr//. Например:

my $pet = 'ELLie';
like $pet, qr/Ellie/, 'Nice puppy!';
like $pet, qr/Ellie/i, 'shift key br0ken';

/i — регистронезависимый поиск.

Модификаторы можно также вставлять внутрь шаблона:

my $find_a_cat = qr/(?<feline>(?i)cat)/;

Отключить модификатор можно через знак -:

my $find_a_rational = qr/(?<number>(?-i)Rat)/;
  • /m — позволяет ^ и $ работать внутри текста.
  • /s — позволяет . захватывать символ новой строки.
  • /r — возвращает изменённую строку, оставляя оригинал нетронутым.
  • /x — позволяет использовать пробелы и комментарии в шаблоне для читаемости.
  • /g — глобальный поиск.
  • /e — выполняет код справа от замены.

Примеры:

my $status = 'I am hungry for pie.';
my $newstatus = $status =~ s/pie/cake/r;

/g также может сочетаться с \G для поэтапной обработки строки:

while ($contents =~ /\G(\w{3})(\w{3})(\w{4})/g) {
push @numbers, "($1) $2-$3";
}

Модификатор /e позволяет вставлять вычисляемые выражения в подстановку:

$sequel =~ s{Scarlett( O'Hara)?}{
'Mauve' . (defined $1 ? ' Midway' : '')
}ge;

Умное сравнение

Оператор ~~ делает контекстно-зависимое сравнение двух операндов:

use experimental 'smartmatch';

my ($x, $y) = (10, 20);
say 'Not equal numerically' unless $x ~~ $y;

my $z = '10 little endians';
say 'Equal numeric-ishally' if $x ~~ $z;

Некоторые примеры:

  • Числа сравниваются как числа
  • Строки через eq
  • Массив и скаляр: ищется скаляр в массиве
  • Хеш и скаляр: проверка наличия ключа

Будьте осторожны: механизм сложный, особенно для объектов и сложных структур.

Юникод и регулярные выражения

Perl отлично поддерживает работу с Unicode. Метасимволы \w, \d и \s в регулярных выражениях учитывают символы Unicode по умолчанию.

use utf8;

my $snowman = "☃";
say 'Found snowman' if $snowman =~ /\w/;

Для специальных потребностей используйте модификаторы:

  • /a — ASCII-безопасный режим (только базовые латинские символы).
  • /aa — ещё более строгий ASCII-режим.
  • /u — явное включение Unicode.
  • /l — локаль-зависимый режим сопоставления.

Расширенные регулярные выражения

Perl позволяет использовать комментарии, именованные группы, условия и даже рекурсивные конструкции внутри регулярных выражений.

Комментарии внутри шаблонов

С модификатором /x можно вставлять комментарии:

my $re = qr{
\A          # начало строки
[A-Z]+      # одна или более заглавных латинских букв
\d{2,4}     # от двух до четырех цифр
\z          # конец строки
}x;

Условные выражения

Регулярные выражения Perl могут содержать конструкции типа "если — то — иначе":

/(?(?=PATTERN)THEN|ELSE)/

Пример:

my $check = qr/(?(?=\d{3}-)\d{3}-\d{2}-\d{4}|\d{9})/;

Рекурсивные выражения

Perl позволяет рекурсивно ссылаться на захваченные группы:

my $nested_parens = qr/
\(              # открывающая скобка
(?:             # беззахватная группа
[^()]+      # всё кроме скобок
|           # или
(?&nested)  # рекурсивный вызов шаблона
)*
\)              # закрывающая скобка
/x;

Это позволяет парсить вложенные скобки, цитаты и другие подобные структуры.

Поддержка библиотеки регулярных выражений

Perl использует собственный движок регулярных выражений, но вы можете задать использование альтернативного движка через модуль re::engine:

use re::engine::PluginName;

Например, модуль re::engine::PCRE позволяет использовать совместимость с Perl Compatible Regular Expressions из внешних библиотек.
