Глава 1: Философия Perl

Философия Perl

Perl справляется с задачами: это гибкий, прощающий и пластичный язык. Умелые программисты используют его ежедневно — от однострочных автоматизаций до проектов, длящихся годы и вовлекающих множество разработчиков.

Perl прагматичен. Ты сам решаешь, как решать свои задачи, а Perl подстраивается под твои намерения без лишних сложностей и церемоний.

Perl будет расти вместе с тобой. Уже через час ты сможешь писать реальные полезные программы — и поймёшь, как работает язык и почему он работает именно так. Modern Perl использует это знание и опыт глобального сообщества для того, чтобы помогать писать работоспособный и сопровождаемый код.

Perldoc

Perl уважает твоё время; культура Perl ценит документацию. Perl поставляется с тысячами страниц встроенной документации. Утилита perldoc входит в каждую полноценную установку Perl.

Примеры использования:

$ perldoc List::Util
$ perldoc perltoc
$ perldoc Moose::Manual

Документация также доступна онлайн:

  • perldoc.perl.org — документация Perl
  • search.cpan.org и metacpan.org — документация по модулям CPAN

Как читать документацию

perldoc perltoc — оглавление документации Perl.

perldoc perlfaq — часто задаваемые вопросы.

perldoc perlop — операторы Perl.

perldoc perlsyn — синтаксис Perl.

perldoc perldiag — описание сообщений об ошибках.

perldoc perlvar — список специальных переменных.

Ищи ответы с помощью perldoc -q ключевое_слово или читай о функциях через perldoc -f функция.

Выразительность

Perl разработан так, чтобы напоминать человеческий язык. Это даёт свободу писать код как просто, так и с использованием сложных конструкций. Perl поддерживает разные стили и позволяет выбирать наиболее подходящий под задачу подход.

Например, троекратное умножение списка можно написать по-разному:

my @tripled;
for (my $i = 0; $i < scalar @numbers; $i++) {
    $tripled[$i] = $numbers[$i] * 3;
}
my @tripled;
for my $num (@numbers) {
    push @tripled, $num * 3;
}
my @tripled = map { $_ * 3 } @numbers;

Контекст

Perl меняет поведение выражений в зависимости от контекста — скалярного, списка или отсутствия ожидания результата (void).

Примеры:

find_chores();            # void-контекст
my $one = find_chores();   # скалярный контекст
my @all = find_chores();   # контекст списка

Чтобы явно задать скалярный контекст:

my %results = (
    cheap_operation     => $cheap_results,
    expensive_operation => scalar find_chores(),
);

Типы контекста

Переменные и выражения могут интерпретироваться как числа, строки или логические значения в зависимости от операторов:

say "Ошибка!" if $alice eq $bob;  # строковый контекст
say "Ошибка!" if $alice == $bob;  # числовой контекст

Для принудительного приведения:

my $num = 0 + $x;   # принудительно числовой контекст
my $str = '' . $x;  # принудительно строковый контекст
my $bool = !!$x;    # принудительно логический контекст

Неявные переменные

Переменная $_ — "оно" в Perl. Многие встроенные функции работают с $_ по умолчанию:

chomp;
say;
print;

Также используется в регулярных выражениях и циклах:

while (<STDIN>) {
    chomp;
    say scalar reverse;
}

Оператор "..."

Троеточие ... — заглушка для кода. Perl распознает его как корректный синтаксис, но выбросит ошибку при выполнении.

Стандартные массивы

@_ — массив аргументов внутри функции. @ARGV — аргументы командной строки вне функций.

sub foo {
    my $arg = shift;
}

Чтение ввода

<> — короткая запись для чтения файлов из @ARGV или стандартного ввода:

while (<>) {
    chomp;
    say scalar reverse;
}
