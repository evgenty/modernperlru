Глава 4: Операторы

Операторы

Некоторые называют Perl «языком, ориентированным на операторы». Оператор Perl — это один или несколько символов, которые обрабатывают ноль или более операндов. Операторы работают аналогично специальным функциям, встроенным в синтаксис языка.

Характеристики операторов

Каждый оператор имеет характеристики: количество операндов, отношение к другим операторам, контексты и синтаксис. Подробности можно найти в perldoc perlop и perldoc perlsyn.

Приоритет операторов

Приоритет определяет, в каком порядке Perl выполняет операторы. Операторы с более высоким приоритетом выполняются раньше. Пример:

7 + 7 * 10   # результат 77
(7 + 7) * 10 # результат 140

Таблицу приоритетов лучше просматривать время от времени, а не заучивать.

Ассоциативность

Ассоциативность определяет направление вычислений: слева направо или справа налево. Например:

2 + 3 + 4   # сначала 2 + 3, потом +4
2 ** 3 ** 4 # сначала 3 ** 4, потом 2 в 81 степени

Модуль B::Deparse позволяет увидеть, как Perl реально интерпретирует выражение.

Арность

Арность — это количество операндов:

  • Нулевое: 0 операндов
  • Унарное: 1 операнд
  • Бинарное: 2 операнда
  • Троичное: 3 операнда
  • Списочное: список операндов

Пример для бинарных операторов:

2 + 3 - 4   # сначала 2 + 3, потом -4

Фиксация (Fixity)

Фиксация описывает расположение оператора относительно операндов:

  • Инфиксные: между операндами ($a * $b)
  • Префиксные: перед операндом (-$x)
  • Постфиксные: после операнда ($x++)
  • Охватывающие (circumfix): вокруг операнда ({ ... })
  • Пост-охватывающие (postcircumfix): например, доступ к элементам массива или хэша

Типы операторов

Числовые операторы

Числовой контекст накладывается при арифметических операциях:

$a + $b, $a - $b, $a * $b, $a / $b, $a ** $b, $a % $b

Строковые операторы

Строковый контекст накладывают:

$string1 . $string2   # конкатенация
$string =~ /regex/   # привязка регулярного выражения
$string !~ /regex/   # отрицательная привязка

Логические операторы

Логический контекст создают:

$a && $b, $a || $b, !$a, $a and $b, $a or $b, $a xor $b

Оператор // проверяет определенность значения:

my $name = shift // 'Fluffy';

Тернарный оператор

Три операнда:

my $result = $condition ? 'yes' : 'no';

Побитовые операторы

Работа на уровне битов:

$a & $b, $a | $b, $a ^ $b, $a << $b, $a >> $b

Специальные операторы

Автоинкремент с особенностями:

my $num = 1;
my $str = 'a';
$num++;
$str++;

Оператор повторения:

my @nights = ('nights') x 1001;
my $calendar = 'nights' x 1001;

Оператор диапазона:

my @cards = (2 .. 10, 'J', 'Q', 'K', 'A');

Диапазон в логическом контексте ("flip-flop"):

while (/Hello, $user/ .. /Sincerely,/) {
    say "> $_";
}

Оператор запятой:

$a, $b

Оператор «толстая запятая» (fat comma =>) также автоматически заключает левый операнд в кавычки.

Оператор «троеточие» (...) используется как заглушка, выбрасывающая исключение "Unimplemented".

sub some_example {
    ...
}
