Глава 2: Perl и его сообщество

Perl и его сообщество

Величайшее достижение Perl — это огромное количество доступных библиотек. Ларри Уолл сознательно поощрял сообщество создавать и поддерживать свои расширения для решения любых задач, не раздробляя язык на несовместимые диалекты. И это сработало.

Технический успех Perl неотделим от роста сообщества. Люди пишут библиотеки, строят новые проекты на базе существующих, создают сообщество, в котором хочется участвовать и которое хочется развивать.

Сообщество Perl приветствует участников любого уровня — от новичков до разработчиков самого языка. Используй знания, опыт и код тысяч программистов, чтобы стать лучше.

CPAN

Perl — прагматичный язык. Если у тебя есть проблема, скорее всего, кто-то уже написал код для её решения и поделился им через CPAN (Comprehensive Perl Archive Network).

CPAN — это огромный репозиторий библиотек: от доступа к базам данных до протоколов сетевых устройств, от инструментов профилирования до графических библиотек.

Без CPAN Modern Perl — просто язык. С CPAN — это мощный набор инструментов.

Размер CPAN

CPAN ежемесячно пополняется сотнями новых участников и тысячами новых модулей. Например, в мае 2015 года было зарегистрировано 12 207 авторов, 150 552 модуля и 31 873 дистрибуции.

CPAN — это лишь сервис зеркалирования. Авторы загружают свои дистрибуции на PAUSE, который затем распространяет их по зеркалам. Стандарты сообщества обеспечивают совместимость и удобство работы с дистрибуциями.

Дополнительные сервисы CPAN обеспечивают автоматическое тестирование, отчёты о багах и поддержку через RT. Всё это доступно через search.cpan.org и metacpan.org.

Работа с CPAN

Modern Perl включает клиент CPAN.pm для поиска, загрузки, сборки и установки модулей.

$ cpan
cpan[1]> install Modern::Perl

Или напрямую из командной строки:

$ cpan Modern::Perl

Требования CPAN

Для установки модулей потребуются стандартные инструменты разработки: утилита make и компилятор C. Strawberry Perl включает их. На MacOS требуется установить XCode. На Linux — build-essential.

Инструменты управления CPAN

  • App::cpanminus — лёгкий и быстрый клиент CPAN. Установка: cpan App::cpanminus.
  • App::perlbrew — управление несколькими версиями Perl: 
    $ curl -LO http://xrl.us/perlbrew
$ chmod +x perlbrew
$ ./perlbrew install
$ perldoc App::perlbrew
  • local::lib — позволяет устанавливать модули локально для пользователя или приложения.

Эти инструменты предполагают работу в Unix-подобной системе. Для Windows — рекомендуется скачать Padre all-in-one.

Сообщество

Официальный сайт: perl.org. Там ты найдёшь документацию, исходные коды, списки рассылки и обучающие материалы.

Если ты новичок, стоит начать с списка для новичков.

Разработка Perl сосредоточена на dev.perl.org.

Основные сайты CPAN — cpan.org, search.cpan.org и metacpan.org.

Новости и блоги сообщества:

  • blogs.perl.org
  • perlsphere.net
  • PerlTricks.com
  • Ironman
  • Perl Weekly и @perlbuzz

Разработка

Основной трекер ошибок Perl: rt.perl.org. Трекеры модулей CPAN: rt.cpan.org.

Обсуждение разработки происходит в списке рассылки Perl 5 Porters (p5p).

Perl Foundation поддерживает развитие Perl: perlfoundation.org.

Код многих проектов размещён на GitHub. Проект GitPAN (gitpan) хранит историю всех дистрибуций CPAN.

Мероприятия

Сообщество Perl регулярно проводит конференции YAPC (Yet Another Perl Conference): yapc.org.

Местные группы Perl Mongers регулярно проводят встречи: pm.org.

IRC

Основной сервер сообщества: irc.perl.org.

Основной канал #perl — свободное общение, а для вопросов лучше использовать #perl-help. Модули вроде Moose и Catalyst имеют свои каналы.
